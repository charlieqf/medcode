# MedEvidence Desktop

Download the latest installer from the [Releases page](https://github.com/charlieqf/medevidence-app/releases).

- macOS (Apple Silicon): `medevidence-desktop-mac-arm64.dmg`
- Windows: `medevidence-desktop-win-x64.exe`

> macOS users: first launch needs right-click -> Open to bypass Gatekeeper, or
> run `xattr -cr /Applications/MedEvidence.app` once.

> Windows users: SmartScreen will warn on first run - choose "More info" ->
> "Run anyway".

Source code is maintained privately; this repository hosts only the release
artifacts.
